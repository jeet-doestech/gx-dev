Gate one

Integrated test gate

Preflight review

  • Meaningful implementation exists.
  • Promised tests are present and enabled.
  • No constant-only or vacuous assertions.
  • No secrets, conflict markers, or broad unrelated changes.
  • No accidental vendor or generated files.

Executable evidence

  • Integrate code and tests in staging.
  • Discover project-native verification commands.
  • Record exact command, environment, exit code, and output reference.
  • Classify ownership: developer, test-writer, both, or infrastructure.
  • Never weaken valid tests to produce a pass.
Gate two

Adversarial review

A successful test suite is necessary, not sufficient.

Correctness

Requirements, errors, edge cases, concurrency, and compatibility.

Risk

Security, data loss, performance, migrations, and hidden coupling.

Quality

Maintainability, scope control, test validity, and complexity.

Documentation

After review passes, update affected documentation to match behavior.
