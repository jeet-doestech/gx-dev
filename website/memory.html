Semantic correction pins

Human corrections are stored as intent rather than brittle line diffs. Regeneration must preserve them.

  • Still satisfied → retain.
  • Contradicted by newer evidence → escalate.
  • Target section removed → mark orphaned.
  • Never silently discard a human correction.
Progressive disclosure

Index first, then additive search

Union results, then read relevant pages

Indexes are not truth. Markdown and Git remain authoritative. BM25, vector, graph, and reranking indexes must be rebuildable and evaluated before becoming defaults.

Parallel safety

Reserve names without locking inference

Problem

Two runs can read the same index and independently create near-duplicate pages for the same concept.

authentication.md vs. auth-system.md

Control

  1. Reason outside locks.
  2. Atomically reserve proposed slugs as planned.
  3. Track claimant run IDs as a set.
  4. Degrade a conflicting create to update.
  5. Use conditional hash checks for final writes.
