Core proposition

Non-deterministic work, deterministic gates

Agents can reason creatively, but they cannot promote themselves. gx-dev controls transitions using structured artifacts, Git state, executable verification, and review evidence.

01 / ISOLATE

Independent implementation

Developer and test-writer begin from the same approved contract in separate worktrees, reducing test-to-code collusion.

02 / VERIFY

Evidence-based gates

Exact commands, exit codes, diffs, findings, and revision hashes—not confidence—determine progress.

03 / COMPOUND

Reviewed project memory

Raw captures remain evidence. Only reviewed, provenance-backed conclusions become durable memory.

Operating contract

Where humans stay in control

Always ask the user

  • Clarified requirements
  • Architecture and implementation plan
  • Destructive or difficult-to-reverse operations
  • Material API, security, dependency, framework, or migration decisions
  • Ambiguity exposed after repeated failures

May proceed automatically

  • Minor reversible operational corrections
  • Approved implementation and test tasks
  • Mechanical verification and evidence collection
  • Reviewer-verified documentation updates
  • Final commit after every gate passes
